# PROJECT_JOURNAL_TEMPLATE.md

Copy the relevant template into your actual journal entries (e.g., in `PROJECT_PROGRESS.md` or a personal notes file) at the end of each working session. Consistency here is more valuable than length — a few honest sentences per section beats a skipped entry.

---
